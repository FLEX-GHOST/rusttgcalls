# Support & Community

Need help using `rusttgcalls` or building Telegram VoIP bots? Here are the best ways to get support.

---

## Where to Get Help

### 1. GitHub Issues (Bug Reports & Feature Requests)

- **Bug Reports:** If you encounter unexpected behavior or errors, open an issue using the bug report template. Include:
  - Rust version (`rustc --version`)
  - OS and platform details
  - Minimal reproducible example
  - Verbose logs enabled via `.with_verbose_connection_logs()`
- **Feature Requests:** Open a discussion or issue outlining your proposed feature and use case.

### 2. Direct Contact & Community

For community discussions, questions, or direct assistance:
